TP 2 · Canvas — animation (effet d'écho)

Objectif : animer les cercles concentriques pour créer un effet d'écho : les cercles rétrécissent puis réapparaissent, en boucle.

3.1 Animer avec requestAnimationFrame

Une animation canvas suit toujours le même schéma : 

function animer() {
  // 1. Effacer le canvas : ctx.clearRect(0, 0, largeur, hauteur);
  // 2. Mettre à jour les valeurs (rayon, opacité…)
  // 3. Redessiner
  requestAnimationFrame(animer); // 4.Replanifier la frame suivante
}

3.2 L'effet d'écho complet

On combine : plusieurs cercles, chacun avec un rayon et une opacité issus de la même onde, redessinés à chaque frame.

Vérification

Quand tout fonctionne, la démo affiche des cercles bleus qui pulsent en décalé, comme des ondes dans l'eau — l'équivalent animé du rendu attendu du TP Canvas.

Pourquoi appeler requestAnimationFrame(animer) à la fin de animer() ?

requestAnimationFrame ne fait qu'une frame : sans rappel, l'animation s'arrêterait après un seul dessin. L'appel récursif crée la boucle d'animation, synchronisée sur le rafraîchissement de l'écran.
