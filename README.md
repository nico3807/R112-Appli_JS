# R112-Appli_JS — TP fusionné : Changeur de thème + Canvas

TP de R1.12 Développement Web (BUT MMI Béziers) fusionnant les TP **Changeur de thème** et **Canvas**, sur le modèle du site *bases_de_js* : même thème, même typographie, exercices résolvables directement dans la page (bac à sable intégré).

## Structure

- `index.html` : menu du TD (vue étudiant)
- `td/` : pages d'exercices
  - `td/theme.html` — TP 1 : Manipulation du DOM, changeur de thème
  - `td/canvas.html` — TP 2 : Canvas, dessin statique
  - `td/canvas-animation.html` — TP 2 (suite) : Canvas, animation
- `css/style.css` : charte partagée (identique à *bases_de_js / algorithmique*)
- `js/bac-a-sable.js` : éditeurs exécutables (console intégrée)
- `corrige/` : **corrigés — ne pas diffuser aux étudiants** (non liés depuis l'index)
